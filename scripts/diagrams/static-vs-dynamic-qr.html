Static vs dynamic UPI QR

Static

One print, reuse forever

Encodes pa + pn (and optional fixed am). Customer types the amount unless you baked it in. Change the VPA and you reprint. Fits counters, tables, donation boxes.

Dynamic

New payload per bill

Amount and note are unique each time — invoices, tickets, delivery. A hosted dynamic code can change destination without reprinting the sticker. Needs a live mapping, not only a PNG.

Both still use NPCI upi://pay. A static PNG is not a payment gateway. A dynamic campaign on this site is Clerk-owned and documented in the privacy policy.
