UPI payload

What a UPI QR actually encodes

upi://pay?pa=demo@upi&pn=Demo Shop&am=250.00&cu=INR&tn=Bill

pa

Payee VPA / UPI ID

pn

Payee display name

am

Optional amount

cu

Currency, usually INR

tn

Optional note

Demo payload only — not a live VPA. Any UPI app that reads upi://pay can open it. Official merchant kits from PhonePe or GPay are separate products.
